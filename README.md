# Keel

A personal hybrid training app (CrossFit + bodybuilding): evidence-based programming, fast gym logging, installable on iPhone as a PWA.

- `npm run dev` — local dev server
- `npm test` — engine unit tests
- `npm run build` — production build

Design and programming decisions: [`docs/DECISIONS.md`](docs/DECISIONS.md). Status and next steps: [`docs/PROGRESS.md`](docs/PROGRESS.md).

Training data lives only on the device (and, later, in the owner's own Firebase project). This repository contains no personal data.
